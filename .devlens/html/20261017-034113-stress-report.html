Scale-out (S6)

Partitions and CPU split evenly across workers. At 2 cores per worker throughput goes 40k → 70k → 80k (20k → 13k ev/s per core).

The top knees (3×2 and 2×2) were the host disk, not the workers: spare worker CPU, iowait 6–23 %, up to 10 blocked tasks. On this box the system ceiling is ~90–100k ev/s.

Blue: 6 cores in total. Orange: 2 cores per worker.

Soak stability (S8)

Staging: 16.8M events, 0 lost, 0 duplicates, overall p99 926 ms, RSS 70–139 MB and goroutines 63–75 with no trend. Four windows reached 1.3–2.7 s about every 8 minutes while the Kafka container sat at its 1.0 CPU limit; cause still open.

Local 20-min mini-soak at 45k: 54.0M events, 0 lost, no leak (78 MB RSS, 16 MB live heap after); p99 failed only during two host-disk stalls. The 8-hour soak needs a dedicated broker disk.
