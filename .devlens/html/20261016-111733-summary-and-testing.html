A. Test by hand in the browser (local, newest code)

  1. Open http://150.241.227.64:5173/login, leave the email empty, click Sign in. You are admin.
  2. Connections → New: bootstrap 127.0.0.1:29092, security None → Test. Every step should be ticked.
  3. Create topics dev-me-in and dev-me-out (Browse topics → Create, or let them auto-create).
  4. + New route → Filter & forward. Source dev-me-in. Filter value.eventType equals OrderPaid. In Transform, add Mask on email. Destination dev-me-out. Review → Deploy.
  5. Send events from this machine (command below), then watch Route detail → Overview / Live tail, and Dead letters for the bad event.
ssh root@104.234.195.126 'docker exec -i event-router-staging-kafka-1 /opt/kafka/bin/kafka-console-producer.sh --bootstrap-server kafka:19092 --topic dev-me-in' <<'X'
{"eventType":"OrderPaid","orderId":"o1","email":"john@mail.com","amount":120}
{"eventType":"OrderCreated","orderId":"o2","email":"ann@mail.com","amount":30}
not-json
X
# read the output (expect only o1, email masked)
ssh root@104.234.195.126 'docker exec event-router-staging-kafka-1 /opt/kafka/bin/kafka-console-consumer.sh --bootstrap-server kafka:19092 --topic dev-me-out --from-beginning --timeout-ms 8000'

Expected: only o1 arrives with its email masked; not-json shows in Dead letters as a decode error. Name your topics dev-…, because Kafka is shared with staging.
