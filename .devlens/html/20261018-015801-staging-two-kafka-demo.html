Product bugs fixed

  1. Saved test cases compared the output before destination shaping (key policy, headers, codecs, size limit). Studio and the runtime compare it after. A case pinned in Studio on a key-by-field route therefore failed and blocked deploy. Fix: internal/library/testcases/execution.go.
  2. A deploy that only requested approval superseded the rollout of the version that is live. That version then never became active, and if the request was rejected the route had no current deployment. Fix: SupersedeScope (routes repository, activator, lifecycle, routestore).
