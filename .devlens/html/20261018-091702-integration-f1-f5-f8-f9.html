HttpServicesFactory.test.ts root cause

Vitest 5 fsModuleCache (on by default) keys transforms on file content only, so main reused an old expansion of import.meta.glob('../*/module.ts') that had 12 modules and no push. Fix: WsClient accepts a lazy URL resolved in connect(), and fsModuleCache: false in vitest.config.ts.
