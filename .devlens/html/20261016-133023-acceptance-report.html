Staging skips

Dex has one static user, so the multi-role cases (viewer / editor / approver: TC-APR-01…13, 19, TC-PRV-13, TC-AUD-04, TC-SET-01/02) can't sign in as other users on staging. TC-SEC-02 scans the local worker log only. All of them pass on local. TC-SEC-11 (dev login refused) is staging-only, so it is the local skip.

Cleanup on staging

No acc- topics, DLQ/test topics, consumer groups, connections, alert rules, active tokens, active users or active library objects are left, and the orders-smoke demo route is still running. These remain because the API has no hard delete for them: archived acc- routes, revoked tokens, archived library objects, disabled users, 4 teams from the earlier runs (each owns an archived route), and the reusable fixture team acc-fixture-route-owner. Topics named dev-* come from older e2e suites, not this one, and were left alone.
